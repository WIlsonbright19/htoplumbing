# HTO Plumbing & Radiant

Website for HTO Plumbing & Radiant, serving Alameda and the San Francisco Bay Area.

## Run locally

Requires Node.js.

```sh
npm install
npm run dev
```

## Build and host

```sh
npm run build
```

Publish the contents of `dist/` to any static web host. The build has no server-side runtime or environment-variable requirements, and its relative asset paths also support hosting under a subdirectory. Configure the host's own fallback rule only if you later add client-side routes.
